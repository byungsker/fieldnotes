# Markdown editor extraction and preservation matrix

This matrix tracks the editor behavior inspected in the read-only source
checkout, the extracted package, the Fieldnotes adapter, and its verification.
The source checkout itself is not modified. Publishing, auth, tags, draft
records, autosave, and post metadata remain app-specific and are not part of the
reusable editor.

| Feature | Source implementation | Extraction / Fieldnotes behavior | Verification |
| --- | --- | --- | --- |
| Rich Markdown editing | TipTap 3 Markdown editor in the source app | Rich editing is the default. Only Markdown strings cross the adapter boundary. | Browser smoke: heading/body edited and saved through the API |
| Exact-source escape hatch | Source editor serializes the ProseMirror document on edits | A parse/serialize comparison selects Markdown source mode when syntax would change. Uniform LF/CRLF and terminal newline suffixes are preserved; mixed LF/CRLF and bare-CR input are rejected by the rich path. | Browser verified `# Heading\n\n\nParagraph` falls back; package tests cover line-ending styles and suffixes |
| Frontmatter and properties | Existing Fieldnotes preview hides a closed leading YAML block; storage preserves it | A closed leading YAML block is an exact protected prefix; TipTap edits only the body. Fieldnotes keeps its status, created, folder, updated, and version property controls above the editor. | Browser edited and saved a CRLF frontmatter note in rich mode; API readback matched the exact prefix and line endings |
| Wikilinks | Fieldnotes `remarkWikiLinks` supports title, heading fragment, and alias | Four forms are atomic nodes and retain the exact raw token: `[[target]]`, `[[target#fragment]]`, `[[target|alias]]`, and `[[target#fragment|alias]]`. Preview still handles navigation/backlinks. | Unit cases and live UI title-save verified all four forms unchanged |
| Code blocks | TipTap `CodeBlockLowlight` with common languages and JavaScript default | Toolbar inserts a code block, offers language selection, and copies the active block. | Browser inserted TypeScript block and read back fenced Markdown |
| Formatting toolbar and TOC | Source's legacy toolbar is not used by its current editor page | Reusable accessible toolbar provides headings, emphasis, lists, quote, inline/block code, link, image, TOC, and snippets. | Heading/code-block commands and opening/clicking a TOC entry exercised in Chrome; heading extraction has unit coverage |
| Link dialog and shortcuts | Source link dialog supports Cmd/Ctrl+K and link removal; list indent shortcuts | Structured TipTap marks, URI allowlist, and ProseMirror list commands avoid HTML string interpolation. | Unsafe scheme and editor paste behavior covered by tests/Chrome smoke |
| Bookmark cards | Source embed extension turns a pasted standalone HTTP(S) URL into a preview card and serializes it back to the URL. | Metadata comes only from the injected API adapter; Fieldnotes fetches only public HTTPS targets, pins DNS results, and revalidates redirects. The card renders metadata as text; stored Markdown stays a bare URL. | SSRF unit tests pass; Chrome paste creates a card and saves a bare URL; external metadata retrieval was not tested against a public site |
| Image attachments | Source image flow accepts picker, drag/drop, clipboard, and optimizes before upload | Host injects upload adapter; Fieldnotes accepts PNG/JPEG/WebP source files up to 15 MiB and stores optimized raster data URLs capped at 20,000 characters each. Markdown API bodies remain capped at 250,000 characters; no schema migration or paid storage is used. | Browser compressed a generated PNG to a 19,411-character WebP URL, rejected a 15 MiB + 1 byte file, and saved a 19,439-character body; API boundary test covers 250,000 characters |
| TOC and navigation | Source TOC extracts H1–H3 and has desktop/mobile navigation | Extracted TOC follows live editor headings and scrolls the editor; mobile layout remains usable. | Heading extraction ignores fenced code; responsive screen capture reviewed |
| Snippets and shortcuts | Floating menu supports snippet create/edit/delete/insert and key shortcuts through blog APIs | Storage is an injected adapter; Fieldnotes uses browser-local snippet storage. No blog endpoint or user data is copied. | Browser checked create/edit/delete and `Ctrl+Shift+Q` insertion |
| Placeholder / paste | TipTap Placeholder and Markdown text transform on copy/paste | Retained with image and standalone URL paste handlers. | Chrome image and URL paste checks pass |
| Focus and accessibility | An existing focus stripe was unwanted | The editor has no outline or focus stripe; toolbar, input, and dialog controls retain `:focus-visible` rings in package CSS. | Browser computed editor outline is none; CSS focus-visible rules are present |
| Saved state / conflict / realtime | Source page owns post draft/publish lifecycle | Fieldnotes keeps SQLite transactions, `expectedVersion`, dirty-draft retention, conflict banner, SSE replay, CLI and export paths. | Core suite passes; browser verified UI save → CLI update → preserved dirty draft/conflict → reload recovery |
| Security boundaries | Source OG endpoint validates SSRF; Markdown rendering sanitizes content | No `dangerouslySetInnerHTML`; metadata fetch requires HTTPS, public resolved IPs, DNS pinning, revalidated redirects, and size/time limits. Raw HTML is skipped; images accept only safe web, relative, or bounded raster data URLs. | SSRF tests and unsafe Markdown rendering tests pass |
| Third-party terms | TipTap, Markdown, Lowlight, and icon dependencies | Keep third-party license and notice records with the local reusable package; exclude host branding, secrets, and deployment configuration. | Notice table reviewed; direct dependency versions pinned |

No live SQLite data is rewritten or migrated for editor integration. Regression
and browser fixtures use synthetic Markdown only.
